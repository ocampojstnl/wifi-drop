Getting a file from another device
  1. Open its tile. The number on it is how many files it shares with you; Shared with you marks files meant only for you.
  2. Download. Click a file or its Download button. Download all takes everything at once.
  3. Save. On a computer, Chrome and Edge ask where to save it. On a phone, tap Save when it arrives.

Someone shared a file only with you? If they allowed it, you can give access to other devices too, with the person-plus button next to the file.

{{ad3}}
Sending to one device

Open a device’s tile and use Send files to … only. Nobody else on the network sees those files. You can change who has access any time on the Share page.
